## 🚀 실행 방법

### 요구사항
- Node.js 18+

### 실행

```bash
git clone https://github.com/ksw1360/Library-FrontEnd.git
cd Library-FrontEnd
npm install
npm run dev
```

### 접속
- http://localhost:3000

### 기술 스택
- Next.js 16
- TypeScript
- Tailwind CSS

### 백엔드 연동
- Spring Boot 서버가 http://localhost:9092 에서 실행 중이어야 합니다.
